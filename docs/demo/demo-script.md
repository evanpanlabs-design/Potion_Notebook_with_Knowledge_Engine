# Demo 录屏分镜稿（目标 3 分钟）

> 配合 OBS/QuickTime 录制。前置：库里有 2-3 篇已消化的来源（可用本目录截图对应的演示库）；提前打开 http://localhost:5175 和一个终端（用于回滚演示）。每镜录完可停顿剪辑。

| # | 时长 | 画面 | 操作与旁白要点 |
|---|------|------|----------------|
| 1 | 15s | 终端 + 浏览器 | `npm install && npm start`，打开 :5175。旁白：本地优先，一个命令跑起来，库是纯 Markdown + git |
| 2 | 20s | 总览页 | 展示统计行（19 wiki 页 / 3 来源）与「最近动态」时间线。旁白：每次操作都留痕，ingest/query/note/review 一目了然 |
| 3 | 40s | 投喂页 | 粘贴一篇素材 → 点「投喂并消化」。旁白：两段式管道——先分析出实体/概念/claims，再逐页生成正文；展示 token 成本展示区 |
| 4 | 20s | 总览页 | 刷新后 index 目录新增条目。旁白：闸门校验后落盘，一次 ingest = 一次 git 提交 |
| 5 | 30s | 笔记页 | 新建笔记，输入正文演示 `[[` 补全，点击 wikilink chip 打开抽屉、反向链接。旁白：Note 是一等公民，live-preview 所见即所得 |
| 6 | 40s | 提问页 | 输入跨来源问题 → 回答分三段带引用 chips → 点 chip 跳到 wiki 页。旁白：级联检索 + 强模型；库里没依据时它明说，不编造 |
| 7 | 25s | 审核页 | 队列里选一页预览 → 点「通过」；再选一页点「驳回删除」。旁白：AI 生成的页面默认待审，人是把关人 |
| 8 | 20s | 图谱页 | 展示笔记（琥珀）/实体/概念/来源/问答五类节点。旁白：知识形状自己长出来 |
| 9 | 30s | 终端 | `git -C data/my-wiki log --oneline`，指出第 3 步那次 ingest 提交，`git revert` 后界面变化。旁白：任何操作可整体回滚——信任靠机制不靠承诺 |
| 10 | 10s | 总览/README | 收尾：local-first，纯 Markdown，随时可用 Obsidian 打开 |

## 录制注意

- 浏览器窗口 1920×1080，缩放 100%，隐藏书签栏
- 第 6 步提问耗时约 30-60s（RPM 门控），可剪辑或提前跑好保留结果页
- 第 9 步回滚后记得 `git revert` 恢复，避免影响后续演示
- 若重录第 3 步：同一素材重复投喂会因 sha256 幂等跳过（9ms 秒回），换一篇或改几个字即可重新触发完整管道
