# 卡片盒笔记法（Zettelkasten）

20 世纪 40 年代，德国社会学家尼克拉斯·卢曼发明了一套纸质卡片笔记系统：每条笔记写在一张编号卡片上，卡片之间用编号互相引用。他生前用这套系统写了 70 多本书和 400 多篇论文，产量高得惊人。这套系统后来被称为 Zettelkasten（德语"卡片盒"）。

它的核心不是"记"，而是**连接**：每写一条新笔记，都必须问一句"它和我已有的哪些笔记有关？"，然后显式地链接过去。日积月累，笔记盒不再是仓库，而是一张网——想法之间互相碰撞，产生写作者自己都没预料到的组合。卢曼说："不写笔记，就等于没思考。"

三条基本守则：

1. **一条笔记一个想法**。卡片要短到能一眼看完，长文必须拆。
2. **用自己的话写**。抄原文是收藏，不是思考；只有转述才能暴露理解的空洞。
3. **必须链接**。孤立卡片毫无价值，链接密度决定网络的知识复利。

这套方法在数字时代的继承者是双向链接（backlink）笔记软件：Roam Research、Obsidian、Logseq。你在 A 笔记里链接了 B，打开 B 时能自动看到"被哪些笔记引用过"——链接不再是单向的线，而是双向的桥。

与费曼学习法的关系：卡片盒要求"用自己的话写"，这正是费曼的"教别人"；两者都在用输出倒逼理解。区别在于费曼输出给听众，卡片盒输出给未来的自己。
