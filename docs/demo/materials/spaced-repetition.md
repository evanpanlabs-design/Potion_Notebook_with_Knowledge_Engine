# 间隔重复与遗忘曲线

1885 年，德国心理学家赫尔曼·艾宾浩斯通过自我实验发表了第一条遗忘曲线：学习后 20 分钟忘记约 40%，一天后忘记约 70%，遗忘先快后慢。

对抗遗忘的核心武器是**间隔重复**（Spaced Repetition）：不是一次性长时间复习，而是把复习拆成多次、间隔逐渐拉开的短复习。每次在"快要忘掉"的临界点复习，记忆留存率最高，且每次复习后遗忘速度都会变慢——这条被拉长的间隔序列也叫"最优间隔序列"。

1970 年代，波兰学生皮奥特·沃兹尼亚克据此设计了 SM-2 算法：每张卡片按回忆质量评分，答得好则下次间隔乘以简易系数（约 2.5 倍），答得差则间隔重置。1987 年他基于 SM-2 做了开源软件 SuperMemo，后来的 Anki 是其最著名的继承者，至今仍是医学生、语言学习者的标准装备。

间隔重复与检索练习（retrieval practice）是天然搭档：卡片复习的本质就是"主动回忆"而非"重读"，而主动输出比被动重读更能巩固记忆。这也是为什么"教别人"（费曼学习法）做出的卡片，配合间隔复习效果格外好。

常见误区：把卡片做成"问答题库"一次性刷完。间隔重复的价值在时间分布，不在做题数量——一天刷 500 张新卡，不如 50 张新卡加上按曲线安排的旧卡复习。
