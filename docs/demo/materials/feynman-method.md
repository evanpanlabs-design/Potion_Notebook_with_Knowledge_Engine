# 费曼学习法

费曼学习法（Feynman Technique）由诺贝尔物理学奖得主理查德·费曼的学习实践总结而来，核心是"通过教别人来检验自己是否真正理解"。

四个步骤：

1. 选择一个概念，写在纸的最上方。
2. 用最简单的语言（假设听众是十二岁的孩子）把这个概念解释出来，禁止使用行话。
3. 解释卡壳的地方就是理解的盲区，回到原始材料重新学习该部分。
4. 简化并类比：把解释压缩成流畅的叙述，用类比替换抽象术语。

该方法与检索练习（retrieval practice）高度相关：主动输出比被动重读更能巩固记忆。配合间隔重复使用效果更佳——把每张"教别人"的卡片按遗忘曲线安排复习。

常见误区：把"复述原文"当成"教别人"。费曼式的输出要求重新组织语言，一旦发现自己只是在背诵定义，就说明还没有真正理解。
