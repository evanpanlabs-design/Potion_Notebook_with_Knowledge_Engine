# 录制台本 · 12 步全流程实录（本地可复现）

> 给"拉到本地自己录"的人用。每一步给出：操作、要粘贴的内容（都在 `docs/demo/materials/`）、预期画面、建议停留时长。
> 全程不剪辑也能看：LLM 等待时间保留反而证明"真实"。总时长目标 8-12 分钟。

---

## 第 0 步 · 准备（录前，不入镜或快剪）

```bash
npm install --include=dev   # 沙箱/CI 环境若 omit=dev 需要这个；本地一般 npm install 即可
npm start                   # 一键起 server(3100) + web(5173)
```

另开一个终端，初始化空知识库（UI 没有建库入口，故意的——local-first，库里没东西就先投喂）：

```bash
curl -X POST http://localhost:3100/api/v1/kb
```

确认三件事：`http://localhost:5173` 能打开；`data/` 目录已生成；浏览器窗口调到 1920×1080（录屏清晰）。

**重录注意**：ingest 按 sha256 幂等判重，同素材重投会秒回 skipped。重录前删掉 `data/my-wiki/sources/` 里对应文件即可重跑。

---

## 第 1 步 · 设置 LLM（新功能，必录）

**入镜**：左侧导航「⚙ 设置」。

1. 点击「设置」，介绍：消化（ingest）和问答（query）是两个独立引擎，可以配不同厂商、不同模型、不同协议——OpenAI 兼容、Anthropic，或任何兼容网关（自定义 = 换 Base URL）。
2. 填写两个角色的配置（任选你有 key 的服务）：
   - OpenAI 兼容：协议选 OpenAI 兼容，Base URL 填到 `/v1`，填 API Key + 模型名
   - Anthropic：协议选 Anthropic，Base URL 填 `https://api.anthropic.com`（SDK 自动补 `/v1/messages`），填 key + `claude-sonnet-4-5`
   - 推荐组合：ingest 用便宜快的模型（如 `gpt-4o-mini` / `glm-4.7-flash`），query 用强模型
3. 分别点「**测试连通性**」——绿色 `✓ 连通 xxx ms · 模型名 · 回复「pong」`（**停留 3 秒，这是第一个高光镜头**）。
4. 点「**保存配置**」，横幅提示已保存、立即生效。

**预期画面**：两行绿色连通结果 + 保存成功横幅。

## 第 2 步 · 总览空库（起手式）

**入镜**：「◈ 总览」。

旁白要点：这是个 local-first 的本地应用，纯 Markdown 落盘，没有账号没有云。空库只有一句话提示——知识从投喂开始。

**停留**：3 秒。

## 第 3 步 · 投喂第一篇：费曼学习法

**入镜**：「⇪ 投喂素材」。

1. 素材文件名填 `feynman-method.md`
2. 正文粘贴 `docs/demo/materials/feynman-method.md` 的全文
3. 点「**投喂并消化**」→ 按钮变成"引擎正在消化素材（约 1 分钟）"，下方显示 `LLM 分析 → 生成 → 闸门校验 → 落盘`

**等待期间旁白**（消化要等真 LLM，别剪掉，这是真实性）：
- 两段式：先让便宜模型做要点分析，再生成结构化 wiki 页
- 每一页落盘前过 TypeBox schema 闸门，不合格自动回喂修复一轮
- 生成页全部进审核队列，人审通过才算知识

**预期画面**：消化完成后展示结果面板——生成了哪些页（实体/概念/来源摘要）、token 用量、git commit sha。

**停留**：8 秒，读一遍产出页列表。

## 第 5 步 · 总览：目录与时间线成形

**入镜**：「◈ 总览」。

**预期画面**：统计卡数字上涨；「库目录 · INDEX.MD」出现 entities / concepts 分组 wikilink；「最近动态」时间线有两条蓝色 `ingest`。

**旁白**：每次操作都写进 log.md 并单独 git 提交——这就是"回滚"的底气。

**停留**：6 秒，鼠标划过时间线。

## 第 6 步 · 提问：跨来源作答（核心高光）

**入镜**：「◎ 提问」，输入框粘贴：

```
费曼学习法和间隔重复怎么配合使用？
```

**等待**：真 LLM，10-40 秒，别剪。

**预期画面**：分段回答（组合方式 / 科学依据 / 实践工具），正文内嵌引用 chips（如 `检索练习`、`SM-2 算法`、`费曼学习法`）；下方"本次检索命中的页面"带检索分数；末行"问答已归档：wiki/queries/…"。

**动作**：鼠标点一个引用 chip → 右侧抽屉打开对应 wiki 页 → 点抽屉里 frontmatter 的 `sources[]` → 跳到原始素材。

**旁白**：每个论断都能点到出处，AI 说的每句话可溯源。

**停留**：15 秒。

---

## 第 7 步 · 提问：无依据不编造（第二个高光）

同一页面，输入：

``
康奈尔笔记法和卡片盒笔记法应该怎么组合使用？
```

（库里没投喂过康奈尔笔记法，引擎应该拒答。）

**预期画面**：红色/警示文案"库内没有回答这个问题所需的依据。引擎不会编造——投喂相关素材后再来问"，下方仍列出检索命中的近似页面与分数。

**旁白**：宁可说不知道，也不编——这是信任设计的底线。

**停留**：6 秒。

---

## 第 8 步 · 写笔记：人写的知识 + 双向链接

**入镜**：「✎ 笔记」→「+ 新建」（自动命名"未命名笔记"，无弹窗打断）。

粘贴以下正文（含两条 wikilink，会实时高亮成 chip）：

```markdown
今天把两个学习方法接到了一起。

费曼的"教别人"其实就是检索练习：输出越主动，记忆越牢。那把每次"教别人"的产物直接做成卡片，再按遗忘曲线安排复习，就是一套完整的闭环——[[费曼学习法]] 负责理解深度，[[间隔重复]] 负责记忆留存。

卢曼说"不写笔记等于没思考"，我的理解是：输出不是为了存档，是为了暴露自己没懂的地方。
```

点「**保存**」→ 绿色 banner"已保存"（底部提示：自动带 frontmatter 入库、提交 git）。

**动作**：Ctrl/Cmd 点击 `[[费曼学习法]]` chip → 抽屉打开 → 展示「反向链接 · 被哪些页面引用」面板里有刚写的笔记。

**停留**：12 秒。

---

## 第 9 步 · 审核：人审把关

**入镜**：「☑ 审核」。

1. 左侧待审队列（第 3/4 步产出的所有页都在），点选一条概念页（如 `遗忘曲线`）
2. 右侧预览：frontmatter 的 `sources[]`、正文结构
3. 点「**✓ 通过**」→ 队列计数 -1，绿色横幅
4. 再随便选一条，点「**✕ 驳回删除**」→ 该页从库里消失（git 里也有删除提交，可回滚）

**旁白**：AI 生成的一切默认不可信，人审通过才算正式知识；审核动作本身也进 git、进 log。

**停留**：12 秒。

---

## 第 10 步 · 知识图谱：网的形状

**入镜**：「⟡ 知识图谱」。

**预期画面**：力导向图——实体蓝、概念紫、来源灰、问答绿、**笔记琥珀色**；你的笔记节点连着 `费曼学习法` 和 `间隔重复`。右上角图例可对照。

**动作**：拖一下画布；点笔记节点开抽屉。

**旁白**：这一步没有任何人工整理——网是投喂、提问、写笔记自然长出来的。

**停留**：10 秒。

---

## 第 11 步 · 回滚（信任设计的底牌，可选但强烈建议录）

终端操作（画中画或切屏均可）：

```bash
cd data/my-wiki
git log --oneline | head -8          # 一次操作一次提交
git revert --no-edit <第9步通过"遗忘曲线"那次提交的sha>
```

回到浏览器刷新审核页：`遗忘曲线` 回到待审队列（`reviewed` 标记随 revert 消失）。再 `git revert --no-edit <revert提交>` 恢复。

**旁白**：任何一步都可以整体反悔——git 是知识库的时光机。

**停留**：5 秒，结束录制。

## 附录 B · 录制注意

- 分辨率 1920×1080；浏览器缩放 100%
- LLM 等待是特性不是缺陷：可以变焦/画中画，但别剪成"秒出"
- ingest 有 RPM 门控（每分钟请求数限制），连续投喂可能排队等几秒，正常
- 重录某个 ingest 前，删 `data/my-wiki/sources/<对应文件>`（幂等判重以来源文件 sha256 为准）
- 全程键盘操作少、鼠标路径稳，观感会好很多
